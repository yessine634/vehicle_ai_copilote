# Agentic AI Copilot for Intelligent Vehicle Decision Support

Software-only Python project for an agentic vehicle decision-support copilot.

The project is being developed incrementally in this order:

1. Weather
2. Routing
3. Vehicle simulator
4. Diagnostic machine learning
5. Retrieval-augmented generation over vehicle manuals
6. LLM integration
7. LangGraph workflow
8. Streamlit interface

The current development stage is **Weather**. The other modules are placeholders for future work.
